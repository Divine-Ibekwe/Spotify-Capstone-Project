# Spotify Customer Subscription Behaviour Analysis

A data analysis and machine learning project exploring the subscription preferences of Spotify users. Using a survey dataset of 520 users, the project examines how demographics, music preferences and listening behaviour relate to Free and Premium subscriptions.

The project involved data cleaning, exploratory data analysis, data visualisation and building a Logistic Regression model using Python and Scikit-learn, achieving approximately 72% prediction accuracy.

**Key Tools:** Python, Pandas, Matplotlib, Scikit-learn.

**Objective:** Generate insights that can support targeted marketing, premium subscription conversion and customer retention.
